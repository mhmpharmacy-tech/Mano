# مانو کید (MANO Kid) — اپلیکیشن وب راهنمای سلامت، دارو و رشد کودک

مانو کید یک اپلیکیشن وب تمام‌راست‌به‌چپ (RTL) با React، TypeScript، Tailwind CSS و سرور Express است که ابزارهای بالینی آفلاین/کلاینت و قابلیت‌های هوشمند مبتنی بر Gemini را برای والدین و مراقبان کودک ارائه می‌دهد.

## قابلیت‌های اصلی
- **بررسی علائم کودک (Triage):** ارزیابی تب، سرفه، یبوست، اسهال/استفراغ، سوختگی پوشک و درد گوش با قفل‌های ایمنی نوزاد زیر ۳ ماه و پرچم‌های قرمز اورژانسی.
- **محاسبه‌گر ایمن دوز تب‌بر و خط زمانی ۲۴ ساعته:** محاسبه دقیق میلی‌لیتر استامینوفن و ایبوپروفن بر پایه وزن، تصویرسازی سرنگ مدرج، قفل سنی زیر ۳ و زیر ۶ ماه و هشدار تداخل زمانی.
- **اسکنر هوشمند شربت و تطبیق غلظت:** تحلیل تصویر برچسب بطری یا انتخاب نمونه و تطبیق غلظت `mg/mL` با تأیید الزامی والد.
- **نمودار رشد WHO و نقاط عطف تکامل:** محاسبه دقیق Z-score و صدک قد/وزن برای دختر و پسر بدون پیش‌فرض ساختگی.
- **برنامه واکسیناسیون کشوری:** تبدیل تقویم شمسی و میلادی، وضعیت واکسن‌های انجام‌شده/عقب‌افتاده/پیش‌رو و یادآور محلی.
- **برنامه درمانی روزانه، مشاور تغذیه (+۶ ماه)، دارونامه (۱۰ دارو + تداخل)، پرسش‌های متداول (۳۴ مورد + پاسخ مستند)، مکمل و بهداشت، تجهیزات خانگی و پرونده کودک.**

## اجرا و توسعه محلی
```bash
npm install
npm run dev
```

برای فعال‌سازی قابلیت‌های هوش مصنوعی (پیش‌نویس ویزیت پزشک، مشاور تغذیه، اسکنر شربت، چک‌لیست ایمنی و پاسخ‌گوی مستند FAQ)، متغیر `GEMINI_API_KEY` را در محیط سرور تنظیم کنید. تمام محاسبه‌گرهای بالینی و ابزارهای پایش بدون کلید هم فعال هستند.
